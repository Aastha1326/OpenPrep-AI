# Summary

This PR hardens the security of the Node.js Express API. It implements strict `helmet` header integration, configures robust per-IP rate-limiting controls across auth/AI routes using `express-rate-limit`, and integrates double-submit cookie CSRF validation using the modern `csrf-csrf` package.

## Changes Implemented

- **Helmet Integration**: Configured `helmet` security headers for all routes, including strict HSTS rules, no-sniff X-Content-Type-Options, frame-options deny, and a strict Content Security Policy (with a relaxed fallback rule only for the `/api-docs` Swagger endpoint).
- **Granular Rate-Limiting**: Created [`rateLimitMiddleware.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/middleware/rateLimitMiddleware.js) defining:
  - `authRateLimiter`: Limits authentication routes to 5 attempts per 15 minutes.
  - `aiRateLimiter`: Limits AI-powered queries to 30 requests per hour.
  - `generalRateLimiter`: Limits overall API endpoints to 100 requests per 15 minutes.
  - All rate limiters correctly set `Retry-After` headers and return `429 Too Many Requests`.
- **Double-Submit CSRF Protection**: Created [`securityMiddleware.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/middleware/securityMiddleware.js) using `csrf-csrf` to enforce CSRF validation on all state-mutating requests (POST, PUT, DELETE), with double-submit cookie checks, custom headers, and a dedicated token generator endpoint `/api/csrf-token`.
- **Axios Header Hook**: Verified Axios client compatibility for appending the `X-CSRF-Token` header.
- **Unit Testing**: Created [`securityMiddleware.unit.test.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/tests/middleware/securityMiddleware.unit.test.js) and [`rateLimitMiddleware.unit.test.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/tests/middleware/rateLimitMiddleware.unit.test.js) asserting correct initialization and export behavior, passing successfully.
