## Discrepancy Note

The issue description refers to a "Next.js frontend," but the repository implements a **Vite + React** single-page application (React 19, Vite 8, Tailwind CSS, Redux Toolkit, React Router). All documentation and diagrams describe the actual implementation: React/Vite SPA → Express 4 REST API → Sequelize/PostgreSQL, with Redis caching, Socket.IO realtime, JWT + Google OAuth authentication, and Gemini (`gemini-1.5-flash`) AI integration.
