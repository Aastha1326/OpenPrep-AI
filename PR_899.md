# Summary

This PR implements a comprehensive, peer-to-peer tagging, bookmarking, and nested folder system across notes, flashcards, and quizzes. This enables students to organize revision materials hierarchically (e.g. by Subject or Semester), apply custom color-coded tags, and bookmark favorite resources for quick dashboard access.

## Changes Implemented

- **Database Model**: Created the [`Folder.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/models/Folder.js) model with parentId referencing itself for infinite nested folders, along with relationships in [`index.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/models/index.js).
- **Model Modifications**: Updated `Note`, `Flashcard`, and `Quiz` models to support `folderId` and a `tags` array of strings.
- **REST Endpoints**: Created [`folderController.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/controllers/folderController.js) and [`folderRoutes.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/routes/folderRoutes.js) for:
  - `GET /api/folders/tree`: Returns the complete nested folder tree structure.
  - `POST /api/folders`: Handles folder creation.
  - `PATCH /api/folders/:id/move`: Moves folders or sub-items into other folders (preventing cyclical loops).
- **Frontend Directory Tree Components**:
  - `FolderTreeSidebar`: Renders an interactive collapsible tree layout for navigating folders.
  - `TagSelectorModal`: Formats multi-tag editing dialogs.
  - `BookmarkedSection`: Displays starred materials in a quick-access dashboard panel.
- **Testing**: Added unit tests in [`folderController.unit.test.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/tests/controllers/folderController.unit.test.js) asserting correct tree-building logic, passing successfully.
- **Pre-existing Fix**: Resolved a pre-existing syntax error at the end of the `User.js` model file and modernized its imports to CommonJS.
