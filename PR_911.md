# Summary

This PR implements an in-browser PDF reader/viewer with annotation capabilities, including text highlighting (Yellow, Green, Pink, Blue), floating sticky comments/notes, and an option to instantly convert selected highlights into flashcards.

## Changes Implemented

- **Database Model**: Created the [`PDFAnnotation.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/models/PDFAnnotation.js) model to persist highlights (`rectsData` JSONB, pageNumber, color) and comments/sticky notes (`commentText`), associated with users and documents.
- **REST Endpoints**: Created [`pdfAnnotationController.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/controllers/pdfAnnotationController.js) and [`pdfAnnotationRoutes.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/routes/pdfAnnotationRoutes.js) to retrieve and save PDF annotations.
- **Vibrant React Components**:
  - `PDFViewer`: Embeds standard PDF rendering using `react-pdf`/`pdfjs-dist` or custom iframe canvas overlays.
  - `PDFAnnotationToolbar`: Provides tools to select active highlighting color or toggle notes mode.
  - `SelectionContextMenu`: A floating action panel appearing on text selections to trigger highlighting, commenting, or converting text into flashcards.
  - `StickyNoteOverlay`: A comment listing widget overlaying page margins.
- **Testing**: Added unit tests in [`pdfAnnotationController.unit.test.js`](file:///c:/Users/Harshit%20kumar/OneDrive/Desktop/openSource/OpenPrep-AI/backend/tests/controllers/pdfAnnotationController.unit.test.js) asserting correct annotation parsing and storage, passing successfully.
