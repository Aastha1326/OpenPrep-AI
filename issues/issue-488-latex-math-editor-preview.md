## Issue Type

## Summary
Implement a reusable Markdown + KaTeX LaTeX live editor & preview component with mhchem chemical formula rendering support across Quizzes, Notes, and Flashcards interfaces.

## Problem Statement
When students or AI models generate math formulas (e.g., integrals, matrices) or chemical equations (e.g., $\text{H}_2\text{SO}_4$), standard text inputs fail to render them cleanly in real time, causing layout overflow or raw LaTeX syntax errors.

## Current Behavior
LaTeX math expressions are rendered statically in some components, but input fields and flashcard card editors do not support real-time side-by-side editing and previewing.

## Expected Behavior
A reusable `MathMarkdownEditor.jsx` component that displays a split-pane or live togglable editor with KaTeX expression rendering, chemical equation formatting, and shortcut buttons for common math symbols ($\int, \sum, \alpha, \frac{a}{b}$).

## User Story
As a STEM student creating custom flashcards and reading quiz solutions  
I want mathematical equations and chemical formulas rendered clearly in real time  
So that I can easily read complex formulas without parsing raw LaTeX syntax  

## Proposed Solution
1. Enhance KaTeX parser integration using `katex` and `rehype-katex` / `remark-math` in `frontend/src/components/common/MathRenderer.jsx`.
2. Enable KaTeX extensions for `mhchem` (chemical equations).
3. Create `frontend/src/components/common/MathMarkdownEditor.jsx` featuring tabbed "Write" / "Preview" or side-by-side split view.
4. Add quick-insert toolbar buttons for math symbols.

- Refactor: Update `frontend/src/components/FlashcardModal.jsx` and `frontend/src/components/QuizQuestion.jsx` to use `MathRenderer.jsx`.

### Backend Impact
None.

## Acceptance Criteria
- [ ] Render inline math `$E = mc^2$` and block math `$$\int_0^\infty f(x)dx$$` cleanly without breaking container bounds.
- [ ] Render chemical equations cleanly via mhchem or LaTeX math mode.
- [ ] Toolbar buttons insert LaTeX code snippets at cursor position in text area.
- [ ] Real-time live preview updates under 50ms latency as user types.
- [ ] Responsive design works across mobile screen sizes without layout horizontal scroll bugs.

## Edge Cases
- [ ] Malformed LaTeX syntax typed by user -> render graceful inline fallback error indicator without breaking React component tree.

## Security Considerations
Sanitize all rendered HTML using `DOMPurify` to prevent XSS attacks via raw HTML tags in Markdown inputs.

## Accessibility Considerations
Ensure screen readers can read alt text or aria-labels generated by KaTeX for math expressions.

## Performance Considerations
Memoize KaTeX output rendering using `React.memo` and `useMemo` to avoid re-parsing static math strings on re-render.
