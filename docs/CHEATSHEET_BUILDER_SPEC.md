## Supported Features
1. **Multi-Column Printable Layouts**: Configurable 1-column, 2-column, and 3-column dense grid systems designed for standard A4 double-sided cheat-sheet prints.
2. **KaTeX Formula Rendering**: Real-time client-side rendering with mathematical symbol shortcuts ($\alpha, \beta, \int, \sum, \lim, \partial, \sqrt{x}$).
3. **Template Library**: Instant loadable templates for Calculus, Linear Algebra, Physics, Discrete Math, and Computer Science Big-O algorithms.
4. **Vector PDF Export**: One-click printable CSS layout with auto-scaling to fit tight physical page constraints.
